# 🔒 Secure Crypto Autofill (Manifest V3)

<p align="center">
  <img src="icon.png" alt="Secure Crypto Autofill Logo" width="200"/>
</p>

Решение для **безопасного автозаполнения форм авторизации** на кастомных сайтах и локальных IP-адресах (например, панелей мониторинга PRTG, роутеров, ESXi-хостов). 

Браузер Google Chrome часто блокирует стандартный менеджер паролей на незащищенных HTTP или самоподписанных HTTPS-страницах. Это расширение обходит данное ограничение, принудительно внедряя учетные данные в DOM-дерево, при этом **надежно шифруя их прямо в вашем браузере**.

---

## ✨ Ключевые особенности

* **Криптографическая защита:** Все логины и пароли шифруются на лету по стандарту **AES-GCM (256-bit)** с помощью встроенного *Web Crypto API*.
* **Мастер-пароль:** Данные хранятся в `chrome.storage.local` в виде нечитаемого шифротекста. Доступ к ним открывается только после ввода вашего Мастер-пароля.
* **Безопасность сессии:** Мастер-пароль временно удерживается в оперативной памяти фонового процесса (`background.js`) и полностью стирается при закрытии браузера или блокировке хранилища.
* **Обход ограничений Chrome:** Работает на любых локальных IP-адресах (например, `172.19.238.121`) и на страницах со статусом *«Не защищено»*.
* **Визуальная индикация:** Успешно заполненные поля аккуратно подсвечиваются фиолетовым маркером.

## 🛠 Технологический стек

* **Manifest V3** (Актуальный стандарт расширений Chrome)
* **Web Crypto API** (PBKDF2 для генерации ключей, AES-GCM для шифрования)
* **Vanilla JavaScript** (Без сторонних тяжелых библиотек и зависимостей)
* **HTML5 / CSS3**

## 🚀 Быстрый старт и установка

### 1. Клонирование репозитория
Склонируйте проект или скачайте архив с кодом и распакуйте его в отдельную папку:
```bash
git clone https://github.com
```

### 2. Установка в Google Chrome
1. Откройте Chrome и перейдите на страницу управления расширениями: `chrome://extensions/`.
2. В правом верхнем углу включите **«Режим разработчика»** (Developer mode).
3. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку, в которой лежат файлы проекта.

---

## 💡 Инструкция по использованию

1. Кликните на иконку расширения на панели инструментов Chrome.
2. Придумайте и введите **Мастер-пароль** для создания вашего крипто-ключа.
3. В форме добавления укажите параметры целевого ресурса:
   * **Домен/IP:** например, `172.19.238.121` или `my-router.local`
   * **Логин:** `admin`
   * **Пароль:** `your_secure_password`
4. Нажмите **«Зашифровать и сохранить»**.
5. Перейдите на страницу авторизации вашего сайта и обновите её (`Ctrl + F5`). Расширение автоматически подставит данные!

## 🔒 Безопасность (Как это работает?)

Когда вы вводите данные, `crypto.js` генерирует случайную соль (`salt`) и вектор инициализации (`iv`). На основе вашего Мастер-пароля с помощью 100,000 итераций хэширования **PBKDF2** создается ключ, которым зашифровывается текст. В локальное хранилище браузера попадает только объект вида:
```json
{
  "site": "172.19.238.121",
  "login": { "salt": "...", "iv": "...", "ciphertext": "..." },
  "password": { "salt": "...", "iv": "...", "ciphertext": "..." }
}
```
Без знания Мастер-пароля восстановить исходные данные невозможно.
